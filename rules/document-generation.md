---
name: Document Generation Protocol
description: Insert model ID header at top of any generated document or Markdown file
inclusion: always
---

Insert at the top of ANY generated document or Markdown file:
- Chinese: `> **注：** 本文档由 **[model-id]** 模型自动生成。`
- English: `> **Note:** This document was automatically generated by the **[model-id]** model.`

Use exact model ID from current environment (e.g. claude-sonnet-4-6). Never output the literal placeholder `[model-id]`.
