# 文档生成水印（按需启用）

**默认禁用。** 不得为任何生成的 `.md` / 文档自动插入模型来源声明。

**仅当**用户明确要求"标注模型来源"、"加水印"、"署名"、"insert model header"
或类似指令时，按以下格式在文档顶部插入：

- Chinese: `> **注：** 本文档由 **[model-id]** 模型自动生成。`
- English: `> **Note:** This document was automatically generated by the **[model-id]** model.`

使用当前环境中的实际 model id（例如 `claude-opus-4-7`），严禁输出字面占位符 `[model-id]`。
