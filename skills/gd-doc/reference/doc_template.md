## 模板说明

### 章节功能说明

- **一、前言**：项目基本信息、合作方、排期安排
- **二、概述**：需求背景、司机端需求点、现状
- **三、方案设计**：技术方案的详细设计
  - 3.1 接口协议：后端接口变更详情
  - 3.2 Apollo设计：配置管理
  - 3.3 埋点设计：数据埋点方案
  - 3.4 稳定性设计：降级和监控方案
  - 3.5 放量节奏：灰度发布计划
- **四、具体改动点**：代码层面的详细改动
- **五、测试范围**：测试计划和范围
- **六、其他**：补充说明、UI效果图等

### 可生成的章节

当前doc-creator Skill支持自动生成以下章节：
- 2.2 司机端需求点（基于PRD，提取司机端侧需要实现的功能需求）
- 3.1 涉及后端接口协议（基于git diff/代码文件）
- 3.3 埋点设计（基于git diff/代码文件）
- 四、具体改动点（基于git diff/代码文件）

其他章节需要手动填写或后续扩展。
