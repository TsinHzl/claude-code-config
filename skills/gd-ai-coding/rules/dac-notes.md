# Implementation Notes 规则

开发流程期间，维护 `openspec/changes/{req_name}/dac-notes.html file (or markdown)`，首次需要时创建，后续追加。

记录内容：

- **Decisions** — spec 未明确规定、由你自主决定的事项
- **Deviations** — 相对 spec 做出的任何变更及原因
- **Trade-offs** — 捷径、妥协、延迟处理的工作
- **Risks** — 风险、开放问题、上线前需关注的事项

不记录显而易见的事（如"使用了 StatelessWidget"）。不用它做状态管理。
