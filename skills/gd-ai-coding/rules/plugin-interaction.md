# Plugin 模式交互规则

## AskUserQuestion 在 VS Code 插件中的行为

`AskUserQuestion` 工具在 VS Code 插件（`claude -p` 非交互模式）下会返回 `is_error=true`，
内容为 `"Answer questions?"`。**这是预期行为**：插件 UI 已用 ApprovalCard / 内联输入框
把问题展示给用户，并可能在工具返回之前就已经收集到点击结果。

### 调用 AskUserQuestion 前后必须遵守

0. **调用前**：不得输出任何文字（包括"请选择"、选项列表、"正在xxx"/"已xxx"、"即将执行全流程"编号列表等任何内容）——直接调用工具
1. **调用后本轮立即停止**：工具结果无论成功或 `is_error=true`，**不得再生成任何文字**（尤其禁止把选项再写成 `1. 2. 3.` 编号列表、"请选择"、"用户未回答"）
2. **绝对不要**根据 is_error 自行做默认决策、跳过步骤、或改用纯文本重新询问
3. **静默等待**——下一条用户消息即为选择结果，**无论格式**（标准格式 `用户选择了：{选项标签}` 或自由文本均可）。插件会在本轮 `result` 之后注入这条消息
4. 收到用户消息后，通过**语义理解**判断意图，继续执行后续逻辑，**不得要求用户重新选择**

### 示例

```
[你调用 AskUserQuestion → 返回 is_error=true "Answer questions?"]
→ 不输出任何内容，等待用户消息

[用户消息: "用户选择了：跳过，不使用工程知识图谱"]  ← 标准格式
→ 按选项"跳过，不使用工程知识图谱"执行后续逻辑

[用户消息: "已跳过，不使用工程知识图谱"]  ← 自由文本，同样有效
→ 语义等同于"跳过"，执行后续逻辑，禁止输出任何提示
```

反例（禁止）：

```
[你调用 AskUserQuestion → 用户已在插件按钮上点了「重新开始（保留文件）」]
[工具返回 is_error=true]
→ 又输出「1. 继续上次  2. 重新开始（保留文件）  3. 重新开始（回滚变更）」  ← 重复询问，禁止
```

### 文本输入场景

若 AskUserQuestion 的问题无选项（自由文本输入），插件会弹出文本输入框，用户提交后
同样以普通用户消息的形式发送。直接将该消息作为输入值使用即可。
