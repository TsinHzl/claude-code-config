# 跨平台交互降级规则（codex / dsh / 其他非 Claude Code 环境）

> 本规则与 `plugin-interaction.md`（Claude Code / VS Code 插件模式）并列。
> 触发条件：当前运行环境**没有** `AskUserQuestion` 工具（典型：OpenAI Codex CLI、
> DSH CLI/Web）。判断方式：按环境实际可用工具为准，不确定时先尝试纯文本交互。

## 环境判定

| 环境 | 判定特征 | 交互方式 |
|------|---------|---------|
| Claude Code 标准模式 | 有 `AskUserQuestion` 工具 | 调用工具（见 `plugin-interaction.md`） |
| Claude Code 插件模式（`-p`） | 有 `AskUserQuestion`，返回 `is_error=true` | 调用工具 + 静默等待（见 `plugin-interaction.md`） |
| Codex / DSH / 其他 | 无 `AskUserQuestion` | **纯文本问答**（本规则） |

## 纯文本问答规范（codex / dsh）

1. **一次一问**：每个决策点单独输出一条问题，选项以编号列表展示：
   ```
   请选择（回复编号或文字）：
   1. 现在安装并生成
   2. 跳过，不使用工程知识图谱
   ```
   需要自由文本输入时（如 PRD 链接、DDP 需求 ID），直接输出一行问题等待用户回复。
2. **输出后停止等待**：提问的同一轮不再执行任何后续动作，等用户回复。
3. **回复解析**：编号、选项原文、语义等价的自由文本均有效；解析后立即继续流程，
   不重复确认。
4. **禁止**：一次输出多个问题让用户同时回答；用户未回复就自行假设默认选项继续；
   问过的问题在用户回复后再次追问。
5. **multiSelect 场景**（如 CR 修复项勾选）：列编号清单，请用户回复要修复的编号集合
   （如 `1,3`）或「全部」/「跳过」。
6. **等待期间被打断**（用户给了新指令）：先处理新指令中与当前决策点相关的部分；
   无关则按当前流程状态继续，不丢失进度。

## 与流程文档的对应

各 SKILL.md / references 中「必须调用 `AskUserQuestion`（禁止改用纯文本）」的表述，
在无该工具的环境中一律按本规则的纯文本问答执行——「禁止纯文本」条款是为防 Claude Code
标准模式下 LLM 偷懒，不是反对无工具环境使用纯文本。

## 其他平台差异速查

| 能力 | Claude Code | Codex / DSH |
|------|-------------|-------------|
| 进度清单 | `TodoWrite` | 无对应工具则降级为纯文本阶段声明（`> 阶段1/4`），或用环境自有任务工具 |
| sub-agent（CR / 核验 / 测试验证） | `Agent` tool | Codex 必须使用已认证、已通过门禁的独立角色；角色能力、定义、认证或报告缺失时输出 `BLOCKED` 并停止，禁止单上下文自审降级；DSH/其他环境同样不得把自审标记为已完成独立验证 |
| hooks（追踪 / 权限拦截 / 静默更新） | 已安装 | Codex 通过已受信任的 `apply_patch` Hook 运行；Hook 未安装、未受信任、事件 Schema 不可识别或写入路径不可解析时实时增量为 `0`，Git 提交精确统计仍独立运行 |
| `Skill` tool 直调 | 支持 | 不支持，按 SKILL.md 文档逐步执行 |
