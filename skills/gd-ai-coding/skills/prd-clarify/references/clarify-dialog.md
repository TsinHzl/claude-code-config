# Step 3：逐条对话澄清

## 对话原则（参考 brainstorming）

- **一次一问**：每轮消息只问一个问题，不堆砌多个
- **优先级排序**：先 🔴，再 🟡，最后 🔵
- **提供选项**：尽量给出 2-3 个可能的答案选项 + "其他"，降低用户回答成本
- **关联上下文**：每个问题引用文档中的相关段落，帮助用户快速定位
- **追问机制**：如果用户回答引出新的模糊点，可追问一次（不超过一次追问）

## 单轮对话格式

```
[{优先级标记}] 问题 {当前序号}/{总数}

📍 相关段落：「{摘录文档中的相关内容，≤2行}」

{具体问题}

可选回答：
A. {选项1}
B. {选项2}  
C. 其他（请说明）
D. 跳过此问题
```

## 用户响应处理

| 用户回答 | 处理 |
|---------|------|
| 选择 A/B/C 或自由描述 | 记录结论，进入下一问 |
| "跳过" / "不确定" / "后面再说" | 标记为未澄清，进入下一问 |
| "结束" / "够了" / "没有要补充的" | 跳过所有剩余问题，进入 Step 4 |
| "全部跳过" | 跳过所有剩余问题，进入 Step 4 |
| 用户主动提出文档中的其他问题 | 记录为额外澄清项，正常处理 |

## 循环退出条件（任一满足）

- 用户明确说结束
- 所有问题已遍历完
- 🔴 必须项全部已回答或跳过，且满足以下任一：用户对 🟡 连续跳过 3 个，或已跳过超过 🟡 总数的 50%
